PRIVACY NOTES

Your work.
Your control.

Portfolio Labs is built to run in your web browser. FlowState, PromptLab, BudgetBoard, StudyKit, CV Studio and HabitTrack save some information in local browser storage. DataLens sample records are generated for demonstration. RoboRoute maps are held in the active page session. StudyKit loads React and Tailwind from public CDNs and needs an internet connection for its first load.

Local storage

Local data stays in the browser profile on that device. It does not automatically sync to another phone or computer. Clearing browser data may remove saved work, so use each product's export option where available. BudgetBoard and StudyKit include data export; HabitTrack includes backup and restore. CV Studio drafts can be saved locally on the device.

Files and sensitive information

Only import files you have permission to use. Avoid uploading confidential or personal information to tools until a secure upload and retention policy is explicitly provided. The current tools process supported data in the browser.

Integrations and accounts

Google Calendar sync, cloud accounts, remote backups and server push notifications are not connected in this release. Do not treat browser-only reminders as guaranteed alarms.
