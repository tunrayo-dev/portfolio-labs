PRIVACY NOTES

Your work.
Your control.

Portfolio Labs is designed to run in your browser. The current version stores FlowState tasks and PromptLab drafts in local browser storage. DataLens sample records are generated for demonstration. RoboRoute maps are currently held in the active page session.

Local storage

Local data stays in the browser profile on that device. It does not automatically sync to another phone or computer. Clearing browser data may remove saved work, so use each product's export option where available.

Files and sensitive information

Only import files you have permission to use. Avoid uploading confidential or personal information to tools until a secure upload and retention policy is explicitly provided. The current tools process supported data in the browser.

Integrations and accounts

Google Calendar sync, cloud accounts, remote backups and server push notifications are not connected in this release. Do not treat browser-only reminders as guaranteed alarms.

For questions about Portfolio Labs, contact the creator through the public links on the creator's portfolio.
