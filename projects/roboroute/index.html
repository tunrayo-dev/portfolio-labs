Place obstacles on a grid and see how a robot can navigate from start to finish. Uses breadth-first search to find a shortest route on this unweighted grid.

How it works

Breadth-first search explores neighboring cells until it reaches the goal. Since every move has the same cost, the first route found is a shortest path.
