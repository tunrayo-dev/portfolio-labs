How to run each project

  1. C++ Expense Tracker: Open cpp/expense-tracker.cpp in a C++17 environment and compile/run it.
  2. C# Study Cards: Create a .NET console project, add csharp/study-cards.cs, then run with dotnet run.
  3. Python CSV Insights: Install Python 3, open a terminal in the folder and run python python/csv-insights.py.
  4. TypeScript Task Board: Install Node.js and TypeScript, then compile with npx tsc typescript/task-board.ts.
  5. SQL Learning Hub: Open sql/community-learning-hub.sql in PostgreSQL or a compatible SQL client and execute the schema and queries.

Check each file’s comments for input and usage notes. These are source demonstrations, not hosted services.
