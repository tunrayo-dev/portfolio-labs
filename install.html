USE IT ON YOUR PHONE

Take your
workspace with you.

Portfolio Labs can be installed on supported devices as a Progressive Web App (PWA). Add it to your home screen for an app-like experience. An internet connection is required for the first visit and updates; some previously opened pages may remain available offline.

Android · Chrome

Open this site in Chrome, tap the three-dot menu, then choose “Install app” or “Add to Home screen”. If an Install app button appears in the top bar, you can use that too.

iPhone · Safari

Open this site in Safari, tap Share, choose “Add to Home Screen”, then confirm.

Computer

In a supported browser, use the install icon in the address bar or the browser menu's “Install” option.

This is a Progressive Web App (PWA), not yet a Play Store listing. A Play Store release requires a separate Android packaging, testing, privacy and publishing process.
